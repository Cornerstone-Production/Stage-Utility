> ## Upgrading from 1.9.x? One manual step, once.
>
> **If you installed with the one-line installer or Homebrew, this release
> cannot install itself.** In-app updates for those installs are *new in this
> release* — 1.9.x had no way to perform them, so there is nothing on your
> machine that can fetch this. Re-run the installer once and you are done
> forever: every later update, including the next one, applies from
> **Settings → Advanced → Updates**.
>
> Your configuration, history and secrets are untouched — they live outside the
> install directory, and the previous release stays on disk.
>
> **Linux and macOS**
>
> ```bash
> curl -fsSL https://raw.githubusercontent.com/Cornerstone-Production/Stage-Utility/main/install.sh | sudo bash
> ```
>
> **Windows** — in an Administrator PowerShell
>
> ```powershell
> irm https://raw.githubusercontent.com/Cornerstone-Production/Stage-Utility/main/install.ps1 | iex
> ```
>
> **Homebrew**
>
> ```bash
> brew update && brew upgrade stage-utility && brew services restart stage-utility
> launchctl kickstart -k -p "gui/$(id -u)/homebrew.mxcl.stage-utility"   # macOS: brew starts it, launchd may park it
> ```
>
> **A git checkout needs none of this** — it has always self-updated, and still
> does.
>
> If you are unsure which you have, **Settings → Advanced** names it.

## Highlights

In-app updates now work on **every** install method, not just a git checkout.
A one-line-installer or Homebrew box checks for releases, applies them, and
comes back on the new version by itself — the four faults that made that
unreliable on macOS (a service `brew upgrade` never restarts, a stale launchd
label, a spawn launchd parks, and an update script running from the directory
being replaced) are each fixed and covered by tests.

Also in this release: the **patch sheet** (stage inputs, variants, weekly
tweaks, CSV/XLSX import and export), **ScriptView** for running a service
script on a display, layout-editor improvements, and a large reliability pass
over the live event stream.
