Two small things for setting up Home Assistant. Download YAML sits beside Copy
YAML on the Calling cues panel and saves the fragment as stage_utility.yaml,
ready to drop into Home Assistant's packages folder, and it works where Copy
does not: the clipboard needs a secure browsing context that a plain-HTTP
address on the LAN never has. Import from Companion gains Select all and Clear
on each of its two sections; in Single buttons they act on the rows the search
is showing.
