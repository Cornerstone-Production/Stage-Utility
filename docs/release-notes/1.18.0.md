Cues now work with Apple Home through the Stage Utility integration for Home
Assistant, installed from HACS with a host and a token. Every cue is a switch or
a button there, follows the cue list as you add and remove, and Home follows
along without a YAML file or a restart.

A cue pair reads its device's real state from the variable Companion already
publishes for it, worked out from the button itself; a single toggle button
becomes a real switch that way, and a device the table does not know is learned
by pressing the pair on and off once. A cue asked for a state the device is
already in presses nothing, and for eight seconds after a press the reading is
re-checked every second so quick flips land right. Each cue has an Allowed
during a service switch, the rules list is searchable, and REC START and REC
STOP import as one pair.
