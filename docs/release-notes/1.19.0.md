A console runs on a Ross Ultritouch panel. The layout editor has a canvas preset
for each panel, Ultritouch-2, Ultritouch-2-HR and Ultritouch-4, at the panel's
exact pixels with Letterbox fit locked, and a strip starter for each: a row of cue
buttons and a countdown. DashBoard's Browser component shows the console's
address, and the Ultritouch page under Integrations walks through both sides.

The cue button is a new layout object. It binds to a cue from the rules list,
including pairs hidden from Home Assistant, and shows what its device is doing:
on, off, settling in the eight seconds after a press, stale when Companion has
lost the device, dimmed when the cue refuses. A tap presses the opposite half of
a pair or fires a lone cue, and a refusal is shown on the button. On a wall
display it draws and does nothing.

Companion import reads Open and Closed as a pair. Every rule add, edit and delete
is logged. ProdCom retries on the same service-window back-off as every other
integration and reports an outage once, and a healthy Shure charger no longer
reprints its state every poll. In the layout editor the widget palette floats
from Add object and follows the window's height, and the Canvas popover's size
fields fit inside it.
