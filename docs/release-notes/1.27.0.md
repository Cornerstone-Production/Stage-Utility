Cues are easier to make. New cue on the Automation page is a step-by-step dialog
that saves nothing until Create, and a manual cue, one that fires only when
someone presses it, is its own kind with no When or If. It can put a button for
itself on any console as it is made. In the layout editor the Action and Cue
buttons are one Button that either fires a cue or runs an action.

The patch sheet is built for a desk: the volunteer view uses the whole width and
the editor is a spreadsheet. Branding is a page of cards with its own tab and
home-screen icon, the ProVideoPlayer widget can show only the countdown, and the
Mac output helper loads screens from another machine.

## Changed

- Add rule on the Automation page is now New cue, and nothing is saved until Create.
- The layout editor's Action button and Cue button are one Button; its Does setting switches between them, and saved buttons are unchanged.
- A Button that fires a cue obeys Simulate mode, Disarm and the cue's cooldown, and says "Simulated: nothing was sent" when Simulate stopped it.
- ProVideoPlayer now's Compact switch is a Layout choice: Full, Compact or Countdown only. A widget saved as Compact stays Compact.
- Pages sit 8px from the sidebar, and Screens previews run to the edges of their cards.
- A settings file that cannot be read leaves the server running on its defaults, refuses saves to that file until a restart, and names it on /log.
- A released screen can be set up on another server. A Mac output helper, macOS or Windows kiosk installed before this release must be reinstalled before it is released.
- A ServiceCue rundown's back arrow returns to the page it was opened from, and Home's Open History opens History inside the app.

## Improved

- The patch view lays out by the width it has: a side column with this week and the changes, full-width tables, or the stacked phone layout.
- The patch editor has 32px spreadsheet rows, hop chips in one line, and Devices and Weekly assignment beside the sheet. Printing leaves only the sheet.
- Branding can set a tab and home-screen icon, made from one square image and a background colour; the browser tab and phones use it, and the home-screen label follows the app name.
- ProVideoPlayer now can show only the time left, as large as the widget allows, and can turn it amber then red near the end of a clip.
- The Home SPL card's right-click menu chooses the Smaart metric it reads.
- The Mac output helper loads pages from another machine under its one Local Network permission, shows "Can't reach" instead of a browser error page, and `--new-token` replaces an output's token.
- In Safari, a video feed starts the moment it can play.
- Recording keeps going when a history or raw file cannot be read, holding its saves beside the file instead of replacing it.
- The same toast shown again replaces the one on screen instead of stacking.
- History's Recalculate and counted switch say why the server refused.
