ServiceCue can go on the web. The server publishes its rundowns to a Cloudflare
page the church deploys for itself, so volunteers off the building's network read
the same pages with no login, and with a Cloudflare token the server keeps that
page up to date. A Listen button plays a video feed's sound on the Video feeds page
and Home, a Lyrics widget shows the slide's words with its ProPresenter group, and
one Timer widget replaces the four timer widgets.

Cues are easier to make: New cue is a step-by-step dialog, and the layout editor's
Action and Cue buttons are one Button. The patch sheet is built for a desk, and
Branding is a page of cards with a home-screen icon. Mac output helpers and Windows
kiosks now update with the server; run each one's installer once more to turn this
on.

## Changed

- Add rule on the Automation page is now New cue, and nothing is saved until Create.
- The layout editor's Action button and Cue button are one Button; its Does setting switches between them, and saved buttons are unchanged.
- A Button that fires a cue obeys Simulate mode, Disarm and the cue's cooldown, and says "Simulated: nothing was sent" when Simulate stopped it.
- ProVideoPlayer now's Compact switch is a Layout choice: Full, Compact or Countdown only. A widget saved as Compact stays Compact.
- Pages sit 8px from the sidebar, and Screens previews run to the edges of their cards.
- A settings file that cannot be read leaves the server running on its defaults, refuses saves to that file until a restart, and names it on /log.
- Run the installer once more on each Mac with the output helper and each Windows kiosk; after that they update with the server.
- A released screen can be set up on another server. To move a Mac output helper, macOS or Windows kiosk installed before this release to another server, reinstall it first; one that stays on its server needs nothing.
- A ServiceCue rundown's back arrow returns to the page it was opened from, and Home's Open History opens History inside the app.
- One Timer widget, its Source set to Service, ProPresenter or Baptism, replaces the PCO countdown, Service timer, ProPresenter timer and Baptism timer. Placed timers look as they did, except that a PCO countdown counting up on an item with no length no longer turns amber, and a ProPresenter timer shows a dash and says so while ProPresenter isn't answering.
- Other websites open in a browser on the network can no longer read the server's state, settings or log.
- A stored password for ProdCom, OBS, Smaart, ProVideoPlayer, a Spectera base station or a pulled camera is cleared when its address changes, unless it is typed again in the same save.
- A config import or snapshot recall is checked the way a save is: one bad file refuses the whole restore and nothing changes. Passwords and tokens never come from a restore.
- The server notes every host name it is reached by, and Settings > Advanced > Host names can refuse any name not on its list. Refusal is off until turned on, and turning it on asks you to confirm which names to keep. The list, the Public address and a config restore can only be changed from the server's IP address or a name already on the list.

## Improved

- The patch view lays out by the width it has: a side column with this week and the changes, full-width tables, or the stacked phone layout.
- The patch editor has 32px spreadsheet rows, hop chips in one line, and Devices and Weekly assignment beside the sheet. Printing leaves only the sheet.
- Branding can set a tab and home-screen icon, made from one square image and a background colour; the browser tab and phones use it, and the home-screen label follows the app name.
- ProVideoPlayer now can show only the time left, as large as the widget allows, and can turn it amber then red near the end of a clip.
- The Home SPL card's right-click menu chooses the Smaart metric it reads.
- The Mac output helper updates itself with the server, never during a service, and is put back if the new one does not start. Screens and Screen settings show its version and update state, with Update now and Try again; Settings > Advanced can turn it off.
- A Windows kiosk's launcher updates itself with the server, taking effect at the next sign-in.
- The Mac output helper loads pages from another machine under its one Local Network permission, shows "Can't reach" instead of a browser error page, and `--new-token` replaces an output's token. Reinstall the helper to get these.
- In Safari, a video feed starts the moment it can play.
- Recording keeps going when a history or raw file cannot be read, holding its saves beside the file instead of replacing it.
- The same toast shown again replaces the one on screen instead of stacking.
- History's Recalculate and counted switch say why the server refused.
- The Public link card on the ServiceCue presets page publishes ServiceCue to the church's own Cloudflare page, with the link, Copy and a QR code, and says when Planning Center can't be read or a firewall is intercepting the connection.
- With a Cloudflare account ID and API token on the Public link card, the server updates the public page itself after each update, never during a service; Update the page now does it by hand.
- Listen on the Video feeds preview and Home video cards plays one feed's sound at a time, with a level meter and a remembered volume. A feed that sends AAC needs ffmpeg on the server: the installers add it, and Settings > Advanced shows whether the server can use it.
- The Lyrics widget, for walls and Home, lays the slide's words out Above or Beside its group tag, or as the song's whole Arrangement with the current group lit.
- A Video widget whose picture freezes while its connection stays up reconnects by itself.
