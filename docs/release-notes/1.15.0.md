A link you can hand out: `/history` now shows only the record. No sidebar, no
header, nothing else to click through to. Settings → Advanced is one sheet: the
Update card, then a Server card and a Data card side by side with every control
in view and no disclosures to open. Track, update mode and clock format are
buttons, not dropdowns.

The ProVideoPlayer widget gains a compact mode that leads with the countdown, and
the Companion module can read that same timer as a variable. History lists a
service while the room is still filling, and pacing can be reset mid-service.

Two fixes worth knowing about. YouTube's My broadcasts mode never worked, since
1.11.0, because the check sent a request Google refuses; it works now. And the
Updates mode setting was never saved, so a server set to install automatically
stayed on Manual. Check yours after this update.

## New

- `/history` renders without the app shell, so the link handed to volunteers shows the record and nothing else. `/history/manage`, the operator's page, is unchanged.
- ProVideoPlayer now has a Compact switch: the countdown leads, the state word sits in the caption, and a Label choice picks the cue name, file name, file name with extension or layer name.
- Pacing can be reset during a service from the pacing widget's right-click menu and from History → manage. Items and their recorded times are untouched.
- History lists a service as soon as attendance starts recording, an hour before the first item goes live, so you can watch the room fill.
- When another Stage Utility holds port 8788, the log names it and its data directory, and a copy started from the wrong data directory says so on Settings → Advanced.

## Changed

- Settings → Advanced is one sheet: the Update card, then Server and Data cards, every control inline. Update track, Updates mode and Clock format are segmented buttons; time zone, update day and update hour stay dropdowns.
- The History sound-level trend defaults to the longest LAeq window the meter offers, so it plots the smoother line.

## Improved

- Leaving the console page with unsaved edits no longer freezes the whole page; the view transition never waits on the Discard dialog.
- Captions older than four hours leave the transcript widget and do not come back on a reconnect. A partial line that stalls clears on its own, and the log says which channel and for how long.
- The people counter no longer blinks to a dash when Vea rejects one poll, and two instances sharing one API client no longer log each other out every minute.
- Status tiles hold the height of the connection tile beside them, and the readout's value line no longer clips the tail of a g.
- Downloads are dated in the app's time zone, not the server's clock.
- A Planning Center item that was already live before the service record opened is not counted toward pacing.
