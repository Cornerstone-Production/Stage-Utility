Cues drive OBS, and read it, without a Companion button. Start and stop
recording, streaming and the virtual camera from a cue pair; the button shows
what OBS is doing from OBS's own events, and a repeated cue never ends a
recording. YouTube and Resi live status are pair state too, so a console button
shows green while on air.

A pair can read a ProVideoPlayer layer's hidden or muted state, by the layer's
name, with every live layer offered in the State variable list. Every OBS
recording, stream and virtual-camera start and stop is logged.

ScriptView has two addresses: the rundown launcher and every rundown under it at
/scriptview with none of the app's chrome, for a stage tablet, and the same
launcher in the sidebar at /scriptview/manage. The Ultritouch page covers a
blank frame from missing DNS and the reboot a re-uploaded panel needs.
