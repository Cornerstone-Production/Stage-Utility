Every service type now has a default mic-slot board, and a change made while a
plan is selected is saved against that plan alone; the next plan of that type
starts from the default. A plan switcher in the slots editors steps through
upcoming plans, the preview draws that plan's board with its people, and Now
returns to the plan the screens follow. Export plan moves one
service type's whole setup to another install.

Rules can be called by name with a token, press Companion buttons, and refuse
while a service is live. Import from Companion turns ON/OFF pairs and
single buttons into cues; a cue follows its button when it moves, refuses when
the button is gone, and renames itself with the button's label while its old
name keeps answering. Copy YAML gives Home Assistant switches Siri can say, and
a pair bound to a Companion variable shows its real state.
