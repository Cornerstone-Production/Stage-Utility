Every service type now has a default mic-slot board, and a change made while a
plan is selected is saved against that plan alone. The next plan of
that type starts from the default, and a plan's board is dropped a month
after the plan. A pill in the editor picks the side you are editing, with
Revert to default and Set as default behind it. A plan switcher in the slots
editors and the layout editor steps through upcoming plans, and Now returns to
the plan the screens follow. The editor never changes what the screens show.

Rules can be called by name: one with the Called by name trigger runs on `POST /api/cues/<name>` with a token minted under Settings → Automation,
and refuses while a service is live or about to start. A new action presses a
Companion button, Import from Companion turns ON/OFF pairs into cues, and Copy
YAML produces the Home Assistant switches Siri can turn on and off.
