## Highlights

**A layout tile can hold another screen.** Drop an Embedded screen object into a
custom layout and it renders whatever that View is — a slots grid, a dashboard, a
calendar, another custom layout — showing exactly what the display is showing.
Tap a tile to expand it full-screen; Escape or the control comes back. How deep
one view may embed another is bounded, so a layout cannot recurse into itself.

**The Planning Center calendar is a View kind.** A month grid, bucketed in the
app's time zone rather than the server's, with month navigation and a choice of
which calendars appear. It has its own page, it can be routed to a display, and
it embeds in a layout like any other view.

**Live scores.** Follow teams from ESPN's public scoreboard — professional and
college — through a sport-first picker. Followed games appear as a capsule in the
context bar that grows into a live activity and folds back the same way, as a
score strip sized for wall distance, and as a card on Home. A pinned game hands
over to another when it finishes.

**ProVideoPlayer.** Two widgets and two Home cards: the layer list, showing what
each layer holds and how long is left, and a single reading answering what is on
screen now. Automation gains ProVideoPlayer triggers and conditions, and actions
that fire cues and clear, hide, mute and fade layers, each verifying that the
command landed.

**A plan's notes become the pre-service checklist,** on Home and as a layout
object, ticked off as the room is set up.

**The operator app's chrome is smaller.** On a desktop the page's name moves into
the context bar, so the band that used to carry it is gone. A phone gets its own
set of context-bar items, configured separately from the desktop's. A console can
run with no app chrome at all, and the sidebar drawer closes by following your
finger.

**Settings → Integrations is a card grid,** each integration opening into its own
dialog, with a link to its setup guide.

Also in this release: a log page that shows the state of the app, dashboards on a
display gain a top bar and any display can hide its own, the service-pacing widget
can lead with the projected end time, the layout editor's object palette gains a
search box, an icon and its colour are set in one panel, and Planning Center data
stays fresher during a service.
