Stage plots are stage diagrams for every venue, drawn over the room's floor plan, with
a plot of its own for a plan when one is needed. Connection points link to the patch
sheet, the crew reads the plots on a read-only page, and a venue can be published
behind a secret link.

Theme photos sets a service's mic slot photos from one prompt through OpenAI, and each
photo is approved before it shows. The sidebar and the context bar are customized in
place. The ServiceCue layouts page is redesigned. History's Trends and Sound chart plot
the Smaart metric you choose, and Screens previews stay live.

## Changed

- The Public link is on Settings > Advanced, on its own Public link tab.
- A screen's ServiceCue Columns setting is Layout, Edit column presets is Edit layouts, and Row color's By category is By column.
- The context bar is arranged in Customize mode, opened from the bar's menu or from Settings > Advanced > General. The bar configurator is gone.
- ServiceCue's A+ and A- step the text size by 5, and say the size is this browser's.
- In History's Customize, Table columns chooses the table's Smaart metrics and Plot chooses the metric the Sound chart draws.

## Improved

- ServiceCue's first run links Connect Planning Center and No service types to where they are fixed, and the layouts page opens on its Landing page row until a service type is ticked.
