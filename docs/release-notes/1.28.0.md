Every button press is a command now. A Button on a console or on Home asks what it
presses: a Companion key picked from a grid drawn in Companion's own colours, an app
action, or an existing command. The press goes through the Automation page, so
Simulate, Disarm and the activity log always apply. The Automation page is tabs,
shows where each command is used, and renaming one repoints the Buttons that press it.

Mic slots have their own page: named boards that screens point at, built by drag
and drop, each card showing the performer's photo with badges for channel, capsule
and own in-ears read from Planning Center. Home gains Needs attention and tiles that
act in place, and the layout editor's widgets sit on a shelf under the canvas.

## Changed

- On screen, an automation cue is called a command. The API, log lines and Home Assistant entity ids keep "cue".
- Run an action is gone from Buttons. A saved Run an action Button becomes a Button with a command of its own at start, on import and on save; one that cannot be converted says Needs converting.
- The layout editor's Add object popover is replaced by a widget shelf under the canvas. ⌘F (Ctrl F) opens its search, and Enter adds the best match.
- A slots screen or slots widget shows a named board. Existing slot lists become boards at the first start, and a slots screen's display width is in its screen settings.
- Duplicating a view that shows boards asks whether the copy gets its own boards or shares them.
- The Recording tile on Home presses the built-in REAPER and OBS recording commands, so Simulate and Disarm apply to it.
- Companion settings are two cards, with Browse buttons.
- The browser tab icon has no background unless one is chosen, and the tab and home-screen icons each have their own background.

## Improved

- Needs attention on Home lists what is wrong right now, worst first, with the fix beside each row and a Snooze every browser shares until the next service.
- Home tiles open over Home instead of leaving it. The Timer steps the service with Next and Prev, and Recording starts and stops.
- The Companion picker draws keys as Companion does: copied styles, line breaks, text size and alignment, and live variable values, on a grey ground. It fits a narrow inspector, opens large, and Import from Companion can pick by page.
- A Mac helper's output can be switched on or off from Screens, and Control-Option-Command-O opens the helper's window from anywhere.
- Slot cards show channel, capsule and own in-ears badges on the performer's photo, from Planning Center tags, and the board check lists mics with no capsule tag.
- The tab and home-screen icon follow Recolor, in the editor too, with ink that contrasts with its background.
