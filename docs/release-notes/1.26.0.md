A Mac can now drive several screens at once. The Mac output helper is a menu bar
app that turns each of a Mac's displays, and each output port of a Blackmagic
DeckLink or UltraStudio card, into a screen of its own. One command installs it,
it starts at login, and its outputs appear on the Screens page to set up like any
other display.

Stage messages arrive too. A producer sends a short message from a console to
groups of screens, an alert takes those screens over for 30 seconds, and a
console in the group answers with one tap. Screens gains a settings panel beside
the cards, guided screen creation, and a banner naming screens found on the
network that are not set up yet.

## Changed

- On a Mac, the server's launchd job is `com.stageutility.server`. An existing install keeps its old label until the installer is run again, which moves it.
- `scripts/uninstall.sh` also removes the Mac output helper and the Chrome kiosk, and lists their saved state instead of deleting it.
- Restarting, importing a config or recalling a snapshot answers with `relaunchFailure` when the server cannot arrange its own restart, and Advanced shows it.

## Improved

- Screens found on the network are listed as soon as they are heard, a banner at the top of Screens offers Set up or Dismiss for each, and Screens in the sidebar counts them from any page.
- Not set up yet sits directly under the screen cards.
- Screen previews run edge to edge across their card, and every page sits 8px from the sidebar rather than 20px (12px on a phone).
- Video feeds over HLS catch back up to live after a stall, and a WebRTC screen says when it is holding delay in its own buffer.
- Rule fields that take several choices, such as Day of week, are a real multi-select.
- A toast with a button stays 8 seconds and waits while the pointer is on it.
- The Message composer and Messages widgets arrive at a size that fits them when added from the palette.
- Companion's stage messages actions, feedback, variables and presets come with the Companion module update that ships alongside this release.
