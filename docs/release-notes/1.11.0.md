Stage Utility is one app now. The settings window is gone: the operator pages
live at the same address as the displays, behind a sidebar, with the live service
running across the top of every one of them.

Most of what follows comes from that. Views and Displays merged into a single
Screens page that previews what each screen is showing. Home became a dashboard
you build yourself, out of the same widgets you put on a wall. The layout editor
gained a palette you drag from, snapping, and a colour picker. And Resi and
YouTube now sit alongside OBS and REAPER, so the bar can tell you whether you are
actually going out.

## New

- **Screens can enrol themselves.** Plug in a Raspberry Pi, Mac or Windows machine, run one command, and it finds the server on the network and appears on the Screens page waiting to be given a view
- **Resi and YouTube** report whether you are live and for how long — on the service strip, on Home, and as widgets on any screen, alongside OBS and REAPER
- **Home is a dashboard you build**, out of the same widgets you put on a wall: the next service, what is on now, recording and streaming state, screens online, sound level and attendance
- **Consoles** — a view built for someone to touch rather than to watch — have their own pages in the sidebar
- **A view can be exported and imported**, so a layout built on one install moves to another. The import reports anything that needs rebinding rather than failing
- **Wireless telemetry.** Wireless summary and Mic channel read RF, battery, frequency and, on gear that reports it, the runtime remaining

## Changed

- **The settings window is gone.** Stage Utility opens as a full app in the browser, with a sidebar down the left and the page you are on filling the rest. Every settings section is now a page with its own address, so it can be bookmarked, opened in a second tab, and reached with the back button
- **Views and Displays are one page, called Screens.** A card per screen with a live preview of what it is showing; click the preview to open that display, and use the card's menu to rename it, rotate it, edit its layout, or copy its URL
- **Consoles have their own pages,** listed in the sidebar under Consoles, and are edited in place rather than in a separate editor window
- **Home is a live dashboard** at the root address — the next service, what is on now, whether anything is recording or going out, screens online, sound level and attendance. It is built from the same widgets as any screen, so anything you can put on a wall you can put on Home
- **The Connect tab is gone.** Bitfocus Companion now sits with everything else under Settings → Integrations
- **The live service strip sits above every operator page** — what is on now, the countdown, the clock, and anything disconnected. It is configurable: drag the split, add or remove items, and space them out
- **Sidebar pages are grouped** by what they are for: Consoles, Content, Screens, Devices, Services and Settings. Service history is now **History**, and choosing which plan is live has its own page
- **Padding and opacity on a layout object no longer apply.** Readouts size themselves from the box they are in, so a hand-typed pad worked against it. Existing layouts keep the values; they simply have no effect
- **Streaming widgets fill with colour when live,** the way OBS status and REAPER status already filled red while recording. Turn it off per widget with **Fill green when live**

## Improved

- **The layout editor** has a widget palette you drag from, snapping with alignment guides, an object lock, and a preview of the layout at other window shapes. Objects can be anchored so a layout survives a screen it was not designed for
- **The inspector is grouped into Content, Look and Place** — what the widget shows, how it is drawn, where it sits. Anything that changes the number is in Content; anything that changes how the number is drawn is in Look
- **One colour picker everywhere,** with opacity, a hex box, the app's own palette, and your own saved colours — kept on the server, so a colour mixed on a laptop is there on the tablet by the desk
- **Every readout is drawn the same way,** sized from the box it is in rather than from a font size somebody typed, so a widget looks right on a phone-sized panel and a 4K wall without being set up twice
- **A view can be exported and imported,** so a layout built on one install can be moved to another; the import reports anything that needs rebinding rather than failing
- **Screens can enrol themselves.** A new display finds the server on the network and appears on the Screens page waiting to be given a view, with installers for Raspberry Pi, macOS and Windows
- **Resi and YouTube** now report whether you are live and for how long, on the bar, on Home and on any screen
- **The wireless widgets read live telemetry.** Wireless summary and Mic channel previously showed nothing at all; they now report RF, battery, frequency and, on gear that provides it, the runtime remaining
- **Update notices** tell you once, when there is somebody there to hear it, and a dialog after an update says what changed
