> **Nothing to do to install this.** No manual step, no config migration —
> update the way you normally would. Three things do LOOK different on screens
> you have already built, so they are named here rather than left to be noticed
> mid-service.

**Resi and YouTube widgets fill with colour when live.** They already matched
OBS status and REAPER status in every other respect, but those two painted the
whole widget red while recording and the streaming pair only coloured the word —
so a row of four read as two bold slabs and two lines of quiet grey text. All
four now behave the same way: filled while active, green for a stream and red for
a recorder. Turn it off per widget with **Fill green when live** in the inspector.

**Wireless widgets show readings.** *Wireless summary* and *Wireless channel* were
reading their telemetry from an endpoint that only ever returned a list of channel
names, so the summary reported nought online however many were live, and a channel
tile drew a dash. They now read live RF, battery, frequency and runtime. If you had
given up on these and taken them off a screen, they are worth another look.

**A Resi stream may show LIVE with no elapsed time.** Resi does not report when a
broadcast started, so the clock is measured from the moment Stage Utility watched
the stream go live. A stream that was already running the first time it looked —
because the integration was set up mid-service, or Resi was unreachable when the
stream began — now shows **Live** with no number instead of a clock counting up
from when the app happened to start looking. The clock returns for the next
stream.
