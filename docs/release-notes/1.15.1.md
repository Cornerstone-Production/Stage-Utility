Four fixes to 1.15.0, nothing new. The shared `/history` page scrolls again;
it could not reach anything below the fold. On Settings → Advanced, the Back up
now row sits inside the card like its neighbours, and the Show commands button's
hover no longer hugs the text. And a retired status tile in the layout editor
now converts to the card that replaced it: a YouTube status tile becomes a
Streaming card set to YouTube, an OBS recording tile a Recording card set to
OBS. Before, every retired tile converted to an empty Embedded view.
