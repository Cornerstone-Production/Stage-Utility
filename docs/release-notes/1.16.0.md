Stage Utility works by touch. On an iPad in Safari the layout editor holds a
finger: tap to select, drag to move, drag a handle to resize, and tap-and-hold
for the menu. Every right-click menu in the app opens on tap-and-hold, and where
a menu was the only way to a setting, a ⋯ button appears on touch devices. Small
controls get a finger-sized target without changing how they look, number
steppers repeat while held, and tooltips open on a tap.

The ProVideoPlayer widget grows into a wall of per-layer tiles. Pick the layer
from a list of PVP's live layers, and the tile always names the layer it watches.
The countdown leads in the full widget; a still shows its cue name instead of
"no duration". Because PVP never reports a still's duration, the PVP card gains
Image duration, and a tile can be told to count a still down from it, for a
rotating pre-roll. A finished clip now reads "ended".
