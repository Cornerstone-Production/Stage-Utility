# Images

Screenshots of the app used by the docs. Every one is made from invented data on a
throwaway server (nobody and nothing in them is real) by a script, so they can be
remade when the UI changes:

```bash
npm run build
npm run docs:screenshots                          # all of them
npm run docs:screenshots -- --only wall-stage-wall,screens-overview
```

How the data is made, and what it cannot show, is in
[scripts/docs-screenshots/README.md](../../scripts/docs-screenshots/README.md).
App pages are 1440x900 in the light theme; screens are 1920x1080 as they render.
